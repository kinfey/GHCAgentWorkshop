# GitHub Copilot 中使用 GPT-5 的完整教程

## 概述

GPT-5 是 OpenAI 发布的最新前沿模型，现已在 GitHub Copilot 中进入公开预览阶段。作为 OpenAI 迄今为止最先进的模型，GPT-5 在推理能力、代码质量和用户体验方面都有显著提升，特别擅长处理端到端的复杂编程任务。

## GPT-5 的主要特性

### 🎯 核心优势
- **卓越的代码生成能力**：能够处理复杂的编程任务，生成高质量、可维护的代码
- **增强的推理能力**：在需要深度思考时自动启用思考模式，提供专家级响应
- **改进的协作性**：真正的编程伙伴，能够主动完成复杂任务而不需要频繁确认
- **端到端任务执行**：擅长执行长期运行的代理任务，能够链接数十个工具调用

### 📊 性能表现
- **SWE-bench Verified**: 74.9% 准确率（GPT-4o 仅 30.8%）
- **Aider polyglot**: 88% 准确率
- **τ-bench telecom**: 96.7% 准确率
- **减少约 80% 的事实错误**相比之前的模型

## 如何在 GitHub Copilot 中启用 GPT-5

### 个人用户

#### 1. 检查订阅状态
- **付费计划用户**：Copilot Individual、Pro 等付费计划可以访问完整的 GPT-5
- **免费用户**：可以访问 GPT-5 mini，功能相对有限

#### 2. 在 VS Code 中启用
1. 确保安装了最新版本的 GitHub Copilot 扩展
2. 打开 VS Code 中的 Copilot Chat
3. 在模型选择器中选择 "GPT-5 (Preview)"
4. 首次使用时确认一次性提示

#### 3. 在 GitHub.com 中启用
1. 登录 GitHub 账户
2. 前往个人设置：https://github.com/settings/copilot/features
3. 启用 GPT-5 功能
4. 在 GitHub Copilot Chat 的模型选择器中选择 GPT-5

#### 4. 在 GitHub Mobile 中启用
- 打开 GitHub Mobile 应用
- 进入 Copilot Chat
- 通过模型选择器选择 GPT-5

### 企业用户

#### 1. 管理员配置
- **Copilot Enterprise 和 Business 管理员**必须在 Copilot 设置中启用新的 GPT-5 政策
- 启用后，组织内的用户将在 VS Code 的模型选择器中看到 GPT-5

#### 2. 用户访问
- 管理员启用后，用户可以在所有支持的平台上使用 GPT-5

## GPT-5 在 GitHub Copilot 中的使用模式

### 🔧 Agent 模式（代理模式）
在 Agent 模式下，GPT-5 可以：
- 自主执行复杂的编程任务
- 进行项目规划和架构设计
- 处理多文件的代码重构
- 执行端到端的功能开发

**使用示例**：
```
@workspace 帮我创建一个完整的 React 待办事项应用，包括状态管理、本地存储和响应式设计
```

### 💬 Ask 模式（问答模式）
在 Ask 模式下，GPT-5 擅长：
- 回答复杂的技术问题
- 解释代码逻辑和架构
- 提供最佳实践建议
- 调试和故障排除

**使用示例**：
```
这段代码的时间复杂度是什么？有什么优化建议？
```

### ✏️ Edit 模式（编辑模式）
在 Edit 模式下，GPT-5 能够：
- 精确修改现有代码
- 重构和优化代码结构
- 修复 bug 和安全漏洞
- 更新代码以符合最新标准

**使用示例**：
```
/edit 将这个函数重构为 TypeScript，并添加错误处理
```

## 最佳实践

### 💡 充分利用 GPT-5 的技巧

#### 1. 明确的任务描述
- 提供详细的需求说明
- 包含功能规格和设计要求
- 指定技术栈偏好

#### 2. 善用上下文
- 利用 `@workspace` 让 GPT-5 了解整个项目
- 引用相关文件和代码片段
- 保持对话的连贯性

#### 3. 迭代改进
- 使用"让它变得更好"这样的开放性指令
- 让 GPT-5 主动添加功能和改进
- 相信模型的创造力

#### 4. 利用不同推理级别
- 对于复杂任务，让 GPT-5 使用深度思考模式
- 对于简单任务，使用快速响应模式
- 根据任务复杂度选择合适的模式

### ⚠️ 注意事项

#### 1. 模型限制
- 上下文窗口：272k 输入 token，128k 输出 token
- 目前只支持文本和图像输入，输出仅为文本
- 不支持音频输入/输出和图像生成

#### 2. 使用限制
- **免费用户**：每5小时10条消息，每天1条思考模式消息
- **Plus 用户**：每3小时160条消息
- **Pro 用户**：无限制访问

#### 3. 安全考虑
- GPT-5 采用"安全完成"方法，而非简单拒绝
- 在敏感领域（如生物学、网络安全）会提供高层次安全的回复
- 仍可能偶尔输出有问题的内容

## 与其他模型的比较

### GPT-5 vs GPT-4o
- **代码质量**：显著提升，特别在复杂任务上
- **推理能力**：更强的逻辑推理和问题解决能力
- **协作性**：更像真正的编程伙伴
- **可靠性**：减少幻觉，更值得信赖

### GPT-5 vs 竞争对手
- **相比 Claude Opus 4**：在编程任务上表现更佳
- **相比 Gemini 2.0**：在长期任务执行上更稳定
- **相比其他模型**：工具调用错误率减半
