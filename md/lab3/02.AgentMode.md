# 使用 Agent Mode 创建抽奖轮盘应用 - 完整教程

本教程将指导您使用 GitHub Copilot 的 Agent Mode 功能，创建一个功能完整的抽奖轮盘 Web 应用。

## 📋 准备工作

### 系统要求
- Windows、macOS 或 Linux 系统
- Visual Studio Code（最新版本）
- GitHub Copilot 订阅
- 现代浏览器（Chrome、Firefox、Safari、Edge）

### 环境配置
- 确保已安装 Visual Studio Code
- 确保已登录 GitHub Copilot 账户
- 确保有稳定的网络连接

## 🚀 开始创建项目

### 步骤 1：创建项目文件夹

1. **创建工作目录**
   - 在您的电脑上创建一个新文件夹
   - 建议命名为 `lottery-wheel-app` 或 `apps`
   
2. **使用 VS Code 打开**
   - 右键点击文件夹，选择"用 Visual Studio Code 打开"
   - 或启动 VS Code 后，选择 "文件" → "打开文件夹"

### 步骤 2：启用 Agent Mode

1. **打开 GitHub Copilot**
   - 在 VS Code 中按 `Ctrl+Shift+P`（Windows/Linux）或 `Cmd+Shift+P`（macOS）
   - 输入 "GitHub Copilot Chat"
   - 选择 "GitHub Copilot: Open Chat"

2. **选择 Agent Mode**
   - 在 Copilot Chat 面板中找到模式选择器
   - 选择 "Agent Mode"
   - 确保选择 "GPT-5" 作为模型

### 步骤 3：输入需求描述

在 GitHub Copilot Chat 中输入以下完整需求：

```
帮我用 HTML 5 + JS + CSS 3 创建一个抽奖轮盘应用，注意：

功能需求：
- 一等奖一名，二等奖一名，三等奖一名，未获奖
- 分 7 格，用 7 种不同颜色表示
- 奖项随机分布在不同格子上
- 响应式布局，适配手机和桌面设备
- 支持简体中文、繁体中文以及英语的切换

技术要求：
- 使用纯前端技术实现
- 不依赖外部框架
- 包含旋转动画效果
- 添加音效（可选）
- 优雅的用户界面设计

请创建完整的文件结构和代码。
```

## 🎯 应用功能详解

### 核心功能
- **抽奖机制**：点击按钮开始旋转，随机停在某个格子
- **奖项设置**：一等奖、二等奖、三等奖、未获奖四种结果
- **视觉效果**：7 个不同颜色的格子，流畅的旋转动画
- **多语言支持**：简体中文、繁体中文、英语三种语言

### 技术特点
- **响应式设计**：自动适配不同屏幕尺寸
- **纯前端实现**：无需服务器，可直接在浏览器中运行
- **动画效果**：CSS3 动画 + JavaScript 控制
- **用户体验**：直观的操作界面和反馈

完成基础版本后，您可以考虑以下优化：
